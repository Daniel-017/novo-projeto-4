# Controle de Tarefas (To-Do List)

## Sobre o Projeto

Este projeto consiste em um sistema para gerenciamento de tarefas diárias, desenvolvido como parte da Unidade Curricular de Versionamento e Colaboração. O objetivo principal é aplicar boas práticas de Git, como uso de branches, tags e mensagens de commit padronizadas.

## Tecnologias Utilizadas

* Documento txt
* Git para controle de versão 
* GitHub para hospedagem remota 

## Estrutura do Repositório

* /src: Contém o código-fonte da aplicação.
* /docs: Documentação de planejamento e diário de bordo.

## Como executar

1. Clone o repositório[cite: 62].
2. Abra o arquivo *src/main.ext* no seu navegador ou interpretador.
